# Metrics

This folder contains a single summary file describing the calibration exercise in
`projects/reviewer-calibration/`. It is not a performance record and does not
report accuracy, agreement, or throughput numbers for any client or platform.

## What is recorded

- The number of re-scored cases in the calibration exercise.
- The number of cases where the corrected label differed from the original.
- The number of guideline changes proposed.

## What is not recorded

- Inter-annotator agreement (only one reviewer is represented here).
- Client or platform performance.
- Any statistic that would require a real evaluation dataset.
